Common tasks:

- Create a DB
- Populate DB
  - EF Core
- Modify DB Schema
  - Migrations
    - EF Core, .NET
    - Drizzle, JavaScript
- Persist a DB across restarts
- Deployment

Where:

- In AppHost
- In orchestrated app
  - Triggered on startup?
  - Triggered by a custom command on the resource
- In code that runs in dashboard repl terminals

| What do you want to do?            | Where do you want to do it?  | Options                                 |
|------------------------------------|------------------------------|-----------------------------------------|
| Create a database                  | In the AppHost               | AddDatabase                             |
|                                    | In an orchestrated app       | On startup/On custom command            |
|                                    | In a dashboard REPL terminal | Manual commands or script               |
| Seed a database                    | In an orchestrated app       | On startup/On custom command            |
|                                    |                              | EF Core/Drizzle                         |
|                                    | In a dashboard REPL terminal | Script                                  |
| Modify a database schema           | In an orchestrated app       | On startup/On custom command            |
|                                    |                              | EF Core/Drizzle                         |
|                                    | In a dashboard REPL terminal | Script                                  |
| Persist a database across restarts | In the AppHost               | WithDataVolume                          |
|                                    |                              | WithBindVolume                          |
|                                    |                              | WithLifetime                            |
| Deployment                         | In the AppHost               | New database on each deployment         |
|                                    |                              | Old databsae remains on each deployment |
